# راهنمای شروع ArvanAi

این راهنما برای کسی است که اولین بار ArvanAi را نصب می‌کند: از ساخت سرویس هوش مصنوعی در ابرآروان تا اولین گفتگو و کار با ایجنت.

مرتبط: [ایجنت چت](chat-agent.md) · [ارتباط با API ابرآروان](arvan-api.md) · [قوانین و اسکیل‌ها](instructions-import.md) · [README](../README.md)

## ۱. ساخت سرویس در ابرآروان

> نام منوها و دکمه‌های پنل ابرآروان ممکن است با نسخهٔ فعلی پنل کمی فرق داشته باشد. چیزی که مهم است، سه خروجی آخر این بخش است: **کلید API**، **نشانی پایه** و **دسترسی به مدل‌ها**.

1. **حساب کاربری:** در [پنل ابرآروان](https://panel.arvancloud.ir) ثبت‌نام و احراز هویت کنید.
2. **شارژ حساب:** سرویس هوش مصنوعی پولی است. اگر موجودی حساب منفی باشد، API پاسخ `Account is debtor` می‌دهد و پلاگین پیام «حساب ابرآروان شما بدهکار است» را نشان می‌دهد.
3. **AI Gateway:** در پنل به بخش هوش مصنوعی (**AIaaS**) و **AI Gateway** بروید و یک gateway بسازید. نشانی صفحهٔ هر gateway شبیه این است:

   <div dir="ltr">

   ```
   https://panel.arvancloud.ir/aiaas/ai-gateway/<gateway-id>/details/models
   ```

   </div>

4. **مدل‌ها:** در تب **Models** همان gateway، مدل‌هایی را که می‌خواهید فعال کنید. پلاگین بعداً همین فهرست را از API می‌خواند. اگر مدلی را این‌جا نبینید، با این کلید هم در دسترس نیست.
5. **کلید API:** برای gateway یک کلید API بسازید و **همان لحظه کپی کنید**. معمولاً بعداً دوباره نمایش داده نمی‌شود.
6. **نشانی پایه:** API سازگار با OpenAI است و نشانی پیش‌فرض پلاگین برای آن تنظیم شده است:

   <div dir="ltr">

   ```
   https://api.arvancloudai.ir/v1
   ```

   </div>

### بررسی کلید پیش از نصب پلاگین (اختیاری)

در ترمینال، به‌جای `YOUR_API_KEY` کلید خود را بگذارید:

<div dir="ltr">

```bash
curl -s https://api.arvancloudai.ir/v1/models \
  -H "Authorization: apikey YOUR_API_KEY"
```

</div>

| پاسخ | معنی |
|---|---|
| `{"object":"list","data":[{"id":"GLM-5.3",...}]}` | کلید درست است و مدل‌ها در دسترس‌اند |
| `{"error":"Unauthorized","status":401}` | کلید اشتباه است یا فرستاده نشده |
| `Account is debtor` | حساب را شارژ کنید |

> **امنیت کلید:** کلید را در چت، issue، commit یا فایل‌های پروژه ننویسید. پلاگین آن را در Password Safe خود IDE (Keychain در macOS) نگه می‌دارد. اگر جایی لو رفت، از پنل یک کلید تازه بسازید و قبلی را باطل کنید.

## ۲. نصب پلاگین

**پیش‌نیاز:** یک IDE از JetBrains، نسخهٔ 2024.2 یا جدیدتر (IntelliJ IDEA، PyCharm، WebStorm، Android Studio و …).

### از فایل zip

در IDE به **Settings › Plugins › ⚙ › Install Plugin from Disk…** بروید، فایل `arvan-ai-intellij-<version>.zip` را انتخاب کنید و IDE را دوباره باز کنید.

### ساخت zip از سورس

برای build به JDK 21 نیاز دارید. JDK داخل خود IntelliJ کافی است:

<div dir="ltr">

```bash
JAVA_HOME="/Applications/IntelliJ IDEA CE.app/Contents/jbr/Contents/Home" ./gradlew buildPlugin
# → build/distributions/arvan-ai-intellij-0.1.0.zip

./gradlew runIde   # a sandbox IDE with the plugin, for trying it out
```

</div>

## ۳. تنظیم اتصال

به **Settings › Tools › ArvanAi** بروید و این مراحل را انجام دهید:

1. **API key:** کلید را وارد کنید. اگر فیلد خالی بماند، کلید ذخیره‌شدهٔ قبلی حفظ می‌شود.
2. **Base URL:** مقدار پیش‌فرض `https://api.arvancloudai.ir/v1` را تغییر ندهید.
3. **Model:** دکمهٔ **«دریافت مدل‌ها»** را بزنید تا فهرست مدل‌های چتِ gateway شما بیاید. این دکمه همان کلید و نشانی‌ای را به کار می‌برد که در صفحه نوشته‌اید، حتی اگر هنوز Apply نکرده باشید. بعد یک مدل انتخاب کنید.
4. **HTTP proxy (اختیاری):** فقط اگر شبکهٔ شما پراکسی لازم دارد، مثلاً `http://127.0.0.1:10809`.
5. **Apply** را بزنید.

برای کار ایجنتی، مدلی انتخاب کنید که از **tool calling** پشتیبانی کند. مدل‌های Claude، GPT-5.x، `*-Codex`، `Kimi-K2.7-Code`، `GLM-5-Code` و `Qwen3-Coder` مناسب‌اند. اگر مدلی ابزار را نپذیرد، پلاگین خودش به گفتگوی ساده برمی‌گردد.

## ۴. اولین گفتگو

1. پنجرهٔ ابزار **ArvanAi** را از نوار کناری راست IDE باز کنید. راه دیگر **Tools › ArvanAi: Open Chat** است.
2. یک سؤال بنویسید و <kbd>Enter</kbd> بزنید. برای خط جدید از <kbd>Shift</kbd>+<kbd>Enter</kbd> استفاده کنید.
3. **فایل و متن انتخاب‌شده** در ویرایشگر خودکار همراه پیام فرستاده می‌شوند. با کلیک روی چیپ بالای کادر ورودی این کار خاموش می‌شود.
4. با `@` می‌توانید یک فایل پروژه را به پیام اضافه کنید.
5. منوی **مدل** در نوار پایین است و جستجو هم دارد. مدل را در وسط کار هم می‌شود عوض کرد.
6. زبان رابط با دکمهٔ کره کنار «ارسال» عوض می‌شود. پاسخ به همان زبانی می‌آید که شما می‌نویسید.

### از داخل ویرایشگر

با راست‌کلیک روی کد و رفتن به منوی **ArvanAi** این گزینه‌ها را دارید:
- **Explain This Code:** توضیح کد
- **Review and Suggest Improvements:** بازبینی و پیشنهاد
- **Insert File Reference in Chat:** ارجاع `@File#L1-99` به ورودی چت اضافه می‌شود. میانبرش <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> است.

## ۵. کار با ایجنت

دستیار یک ایجنت برنامه‌نویسی است. خودش فایل‌ها را می‌خواند و جستجو می‌کند، و با اجازهٔ شما فایل ویرایش می‌کند و دستور اجرا می‌کند. جزئیات کامل در [chat-agent.md](chat-agent.md) آمده است.

| کار | تأیید شما لازم است؟ |
|---|---|
| خواندن، جستجو و پیمایش کد (`find_symbol`، `find_references`، …) | نه |
| ویرایش یا ساخت فایل (diff در Diff Viewer خود IDE نشان داده می‌شود) | بله، مگر در Settings خاموشش کنید |
| اجرای دستور (build، تست، git) | بله، مگر در Settings خاموشش کنید |

نمونه درخواست‌ها:
- «تابع `sendMessage` کجا صدا زده می‌شود و اگر امضایش را عوض کنم چه چیزهایی خراب می‌شود؟»
- «برای کلاس `ArvanClient` تست بنویس و اجرا کن.»
- «این خطا را بررسی کن: …»

**حالت طرح:** با <kbd>Shift</kbd>+<kbd>Tab</kbd> یا کلیک روی چیپ `⏵ agent` روشن می‌شود. در این حالت ایجنت اول فقط بررسی می‌کند و طرح می‌دهد، و تا شما تأیید نکنید چیزی را تغییر نمی‌دهد.

### دستورهای `/`

| دستور | کار |
|---|---|
| `/clear` یا `/new` | گفتگوی جدید |
| `/resume` | ادامهٔ یک گفتگوی ذخیره‌شده |
| `/compact [تمرکز]` | خلاصه کردن گفتگو برای آزاد کردن context |
| `/mcp` و `/mcp reload` | وضعیت سرورهای MCP |
| `/graphify` | ساخت گراف کد با graphify (اختیاری؛ بار اول با `uv` نصب می‌شود) |
| `/graphify <سؤال>` | پاسخ با کمک گراف کد |
| `/<نام اسکیل>` | اجرای اسکیل‌های `.arvanai/skills/` |

## ۶. شخصی‌سازی برای پروژه (اختیاری)

<div dir="ltr">

```
.arvanai/
  AGENTS.md                 main project instructions
  rules/**/*.md             always added to the system prompt
  skills/<name>/SKILL.md    run with /<name> args
  commands/**/*.md          run with /<name>
  mcp.json                  MCP servers for this project
~/.arvanai/                 the same, for all projects
```

</div>

- اگر از قبل قوانین یا اسکیل‌هایی برای ابزار دیگری دارید (مثلاً `.claude/`، `.cursor/` یا `CLAUDE.md`)، از منوی **⋮ › کپی قوانین و اسکیل‌ها** یک نسخه از آن‌ها را در `.arvanai/` بسازید. فایل‌های اصلی دست نمی‌خورند. جزئیات: [instructions-import.md](instructions-import.md)
- ArvanAi فایل‌های ابزارهای دیگر را نمی‌خواند و تغییر نمی‌دهد. پس می‌تواند در کنار Claude Code، Cursor، Copilot و بقیه بدون تداخل کار کند.

## چک‌لیست اشکال‌یابی

| نشانه | راه حل |
|---|---|
| «کلید API تنظیم نشده است» | کلید را در Settings › Tools › ArvanAi وارد و Apply کنید. |
| HTTP 401 | کلید اشتباه است یا باطل شده. یک کلید تازه از پنل بسازید. |
| «حساب ابرآروان شما بدهکار است» | حساب را در پنل ابرآروان شارژ کنید. |
| HTTP 404 یا «مدل پیدا نشد» | نام مدل را از «دریافت مدل‌ها» انتخاب کنید و مدل را در تب Models همان gateway فعال کنید. |
| «دریافت مدل‌ها» فهرست خالی می‌دهد | هیچ مدل چتی روی gateway فعال نیست. |
| «اتصال به سرور برقرار نشد» | شبکه را بررسی کنید و اگر لازم است HTTP proxy را تنظیم کنید. |
| HTTP 403 با صفحهٔ HTML | یک فایروال یا پراکسی جلوی درخواست را گرفته است. |
| ایجنت فایل نمی‌خواند و فقط گفتگو می‌کند | مدل از tool calling پشتیبانی نمی‌کند. مدل دیگری انتخاب کنید. |
| هر چیز دیگر | منوی **⋮ › لاگ پلاگین** را باز کنید. کلید هرگز در لاگ نوشته نمی‌شود. |

</div>
